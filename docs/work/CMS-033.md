# CMS-033 — Governed Home, category and editorial media assignments

Issue: #333  
Parent roadmap: #278  
Independent visual-release blocker: #230

## Scope

CMS-033 extends the governed media control plane beyond CMS-032 product/variant galleries. It adds a compiled, bounded surface-slot registry for non-product presentation media without introducing arbitrary remote widgets or binary delivery.

Initial slot contract:

- `home.hero` → `home`, maximum 1;
- `home.editorial.small_changes` → `editorial`, maximum 1;
- `category:drawer-organization` → `category`, maximum 1;
- `category:lunch` → `category`, maximum 1.

## Backend implementation

- `surface_media_items` stores stable slot/media assignments, deterministic position, actor fingerprint and referential integrity to `media_assets`.
- `SurfaceMediaService` owns the compiled slot allowlist, category identity revalidation, exact purpose checks, admitted/canonical eligibility, duplicate/cardinality validation, optimistic fingerprints and atomic replace/clear operations.
- `/admin/media/surfaces` is protected by the existing dashboard authentication boundary and shows purpose-correct eligible media for each compiled slot.
- `GET /api/v1/media/surfaces` returns allowlisted metadata only and supports deterministic ETag revalidation.
- Public metadata includes stable slot/category/media identity, semantic label and canonical MIME/dimensions/SHA-256. Private storage disk/path, source provenance, actor fingerprints, Product Master facts, commerce destinations and arbitrary URLs are excluded.
- Delivery fails closed if an assigned asset is later archived, purpose-mismatched, missing or no longer canonical.

## Regression coverage

`SurfaceMediaServiceTest` covers:

- exact compiled slot registry and purpose binding;
- purpose-correct admitted/canonical assignment;
- Draft, archived, wrong-purpose and missing-canonical rejection;
- stale fingerprint and cardinality atomicity;
- protected category identity revalidation;
- fail-closed public delivery after archive.

`SurfaceMediaHttpContractTest` adds:

- Admin authentication protection;
- owner assignment and clear workflow;
- public schema/revision metadata and exact four-slot contract;
- ETag / `304 Not Modified` behavior;
- private storage/provenance/commerce-field non-disclosure;
- HTTP `503 surface_media_invalid` fail-closed behavior after archive.

## Guardrails

- No image upload or derivative-processing changes; CMS-031 remains authoritative for source quarantine.
- No Product/Variant gallery changes; CMS-032 remains authoritative for product galleries.
- No media replacement/rollback UX; reserved for CMS-034.
- No Flutter remote binary loading/cache/fallback implementation; reserved for CMS-035.
- No automatic media admission.
- No protected `Images/` or `mobile/assets/products/**` changes.
- No Product Master, ASIN, Pantone, price/rating or Amazon destination mutation.
- No claim that #230 or final owner visual acceptance is complete.
