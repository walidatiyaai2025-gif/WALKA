## Delivery scope

### CMS-052 — rollback shortcuts and audit UX
- Restore a known immutable content revision into a **new private draft** only.
- Require optimistic current revision plus a bounded operator reason.
- Persist the reason on the immutable `draft_restored` revision receipt.
- Never rewrite history and never auto-publish after rollback.
- Make rollback source/current/live state explicit in Admin UX.

### CMS-053 — freshness/cache/publication observability
- Owner-only content health dashboard and protected JSON health surface.
- Report draft/published revisions, published age, schedule state and freshness classification without payloads/secrets.
- Keep deterministic public ETag/cache metadata aligned with published revision.

### CMS-054 — metadata backup/restore validation
- Canonical metadata-only backup envelope for governed CMS/catalog/media state.
- Include schema, timestamp, record counts and SHA-256 digest.
- Validate candidate restore envelopes fail-closed without mutation.
- Exclude secrets, sessions and media binary bytes.

### CMS-055 — production smoke matrix
- Read-only executable Admin/API/Flutter contract matrix.
- Hermetic CI coverage plus production-safe invocation contract.
- Machine-readable PASS/FAIL evidence and non-zero exit on failure.

## Guardrails
- Product Master IDs/facts, ASIN/Pantone and commerce architecture remain protected.
- No arbitrary SQL restore/import.
- No secrets or authentication material in backup/observability output.
- No destructive production smoke checks.
- No automatic rollback publication.
