# VFIN-051..070 — Asset quality, performance, and release-truth consistency

Status: IN PROGRESS
Parent batch: #275

The branch adds executable final-release gates rather than duplicating PAV/PIMG implementation:

- every `ADMITTED` production PNG is re-inspected through the repository's existing `PavPngInspector`;
- admitted media must remain 1024×1024, 8-bit RGBA, color-profiled, transparent at the perimeter, and inside safe-margin rules;
- provenance dimensions and byte size must match the real admitted binary;
- the existing `PimgProductionAssetProvenanceReader` must report a valid source-admission/provenance relationship;
- admitted + pending + blocked must always total exactly five released variants;
- a 5/5 visual-release state is impossible while any variant is PENDING or BLOCKED.

This deliberately reuses the existing PAV/PIMG authorities instead of creating a parallel validator. Completion evidence is appended after PR CI and latest-main validation.
