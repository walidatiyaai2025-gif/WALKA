# CMS-002 — Dashboard preview, publish, history and rollback controls

Tracking: #287 (parent #278)
Branch: `agent/cms-002-content-controls`

## Goal

Expose the CMS-001 revision primitives through the protected WALKA Control Center so owner-managed content has an explicit Draft -> Preview -> Publish -> History -> Restore workflow.

## Owner-facing surface

`/admin/content`

- lists every registered content entry
- shows stable key/type, current revision, live revision, history count and publication state
- creates a private structured JSON draft under a stable key/type
- links into a dedicated content workspace

`/admin/content/{id}`

- JSON draft editor with optimistic revision token
- side-by-side draft vs published preview
- explicit Publish action
- immutable revision timeline
- Restore-to-draft action for historical snapshots
- clear stale-session conflict messaging

## Safety contract

- existing server-side dashboard authentication only
- existing session-derived SHA-256 actor fingerprint contract
- no public draft API
- no automatic publish on save or restore
- content type is immutable after creation
- public/mobile consumption remains blocked until CMS-003 adds versioned endpoints and mobile cache/fallback handling
- no HTML/JavaScript execution, Product Master facts, ASIN/Pantone changes or unrestricted commerce destinations

## Validation

Feature coverage verifies:

- guest redirect/authenticated access
- navigation visibility
- private draft creation
- invalid/scalar JSON rejection
- draft save + preview
- explicit publication
- stale revision blocking
- restore creates a new draft without changing the live snapshot
- no accidental public CMS endpoint exposure
