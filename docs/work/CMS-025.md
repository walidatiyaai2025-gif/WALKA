## Delivered scope

- Typed Laravel `search.presentation` schema v1.
- Owner-safe Search heading, supporting copy, field placeholder and empty-state copy.
- Deterministic default Featured ordering using every released stable ProductVariant ID exactly once.
- Locked `all` plus protected catalog-category filter identities with editable display labels only.
- Delivery-time catalog validation prevents unknown/missing variants or filters from becoming public.
- Protected `/admin/content/search` draft/save/publish/history/restore workflow with optimistic revision protection.
- Allowlisted `GET /api/v1/content/search` envelope with schema/revision/published-at metadata and ETag support.
- Flutter typed parser, last-known-good SharedPreferences cache, remote -> cache -> bundled fallback and anti-rollback/divergent-same-revision protection.
- App-root content wiring and active Search surface consumption of governed copy/filter labels/default Featured order.
- Search query matching and complete released-catalog membership remain compiled/protected; CMS merchandising cannot hide a query result.
- Responsive/query-completeness/domain/repository regression coverage.
- Legacy Search automation keys remain stable while owner-visible labels stay CMS-driven.

## Guardrails preserved

- Protected `Images/` is untouched.
- Product Master facts, stable Product/Variant IDs, ASIN and Pantone identity remain protected.
- Amazon handoff architecture is unchanged.
- No arbitrary URL, HTML, JavaScript, remote widget or remote search-algorithm execution is introduced.
- No media upload/assignment is introduced in this slice.
- Visual-release blocker #230 remains independent and is not closed by CMS-025.
