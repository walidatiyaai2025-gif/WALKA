# VFIN-071..090 — APK handoff and visual acceptance contract

Status: IN PROGRESS
Parent batch: #275

A deterministic `mobile/tool/vfin_release_report.dart` now reports two separate authorities:

1. `productionMedia` — mechanical admitted/pending/blocked state from production provenance.
2. `ownerVisualAcceptance` — always `REQUIRES_OWNER_REVIEW` from automation; it is never promoted to PASS merely because media reaches 5/5.

This is intentional. CI/APK evidence can prove engineering and production-media mechanics, while crop/framing/color/reference acceptance of Home, Discovery, PDP, Favorites and About remains a real visual review decision.

The release snapshot is covered by tests for exact five-variant counting, fail-closed unknown lifecycle handling, mechanical blocking while pending/blocked media remains, and non-fabrication of owner acceptance even in a synthetic 5/5 case.

APK run/artifact/receipt evidence and per-surface mechanical review are appended only after the branch reaches Green CI. Any active team post-publish or screenshot-review PR remains authoritative for its own scope and is not duplicated here.
