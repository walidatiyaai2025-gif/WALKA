## Scope

Create one reusable empty-state primitive under the shared design system without changing any owner-visible feature page in this atomic slice.

## Delivered

- Added `mobile/lib/design_system/components/feedback/walka_empty_state.dart`.
- Reuses `WalkaSurfaceCard` for the premium surface contract.
- Requires caller-owned title/body copy; the primitive invents no product, account or commerce state.
- Supports either a default decorative WALKA visual or a caller-supplied visual widget.
- Supports an optional CTA only when both label and callback are supplied.
- Uses shared WALKA colors, spacing and typography roles.
- Marks the title as an accessibility heading; the default decorative visual is excluded from redundant semantics.
- Added focused coverage for default rendering, custom visual/action behavior, heading semantics and compact-width 1.3x text-scale safety.

## Validation findings resolved

- Flutter 3.44.9 deprecated `SemanticsNode.hasFlag`; the test now uses the current `flagsCollection.isHeader` API.
- The compact 1.3x harness was corrected to validate the empty-state inside a scrollable page context instead of forcing a false vertical overflow in a non-scrollable test viewport.
- The semantics handle is explicitly disposed before WidgetTester end-of-test verification.
