# CMS-032 · Governed product and variant gallery assignment + ordering

Status: IMPLEMENTING
Issue: #329
Parent roadmap: #278
Supports visual-release blocker: #230
Depends on: CMS-030 / #319 / PR #320 and CMS-031 / #322 / PR #325

## Runtime scope

- Durable product-level and variant-level gallery assignment tables with stable Product/ProductVariant/MediaAsset foreign keys.
- Deterministic 1-based ordering with a maximum of 8 items per target.
- Unique media asset and unique position constraints within each target gallery.
- Assignment accepts only `product`-purpose media that is explicitly `admitted` and has a canonical derivative.
- Draft, archived, wrong-purpose, missing-canonical and missing media fail closed.
- Atomic replace/reorder operations validate target identity, optimistic gallery fingerprint and all media before deleting the existing gallery.
- Empty variant gallery deterministically inherits the owning product gallery metadata; an explicit variant gallery overrides it.
- Protected `/admin/media/galleries` workspace exposes only eligible admitted Product media.
- Public `GET /api/v1/media/product-galleries` exposes allowlisted stable IDs, semantic labels and canonical MIME/dimensions/SHA-256 only.
- Private source/derivative disks and storage paths, provenance, Product Master facts, ASIN/Pantone and commerce destinations are not emitted.
- Public delivery revalidates current media lifecycle/purpose/canonical state and returns fail-closed 503 when a stale assignment points to no-longer-admitted media.

## Safety boundaries

- No media upload/processing changes; CMS-031 owns source validation/quarantine.
- No Home/category/editorial assignments; CMS-033 remains separate.
- No media replacement/rollback history UX; CMS-034 remains separate.
- No Flutter remote binary loading or caching; CMS-035 remains separate.
- No automatic admission and no claim that gallery metadata satisfies #230 visual acceptance.
- Product Master IDs/facts, ASINs, Pantones, Amazon destinations, protected `Images/` and `mobile/assets/products/**` are unchanged.
