## Delivered scope

- `media_assets` source table with immutable ULID identity.
- Bounded media purpose and lifecycle states (`draft`, `admitted`, `archived`).
- Source/provenance reference plus original filename, MIME, byte count, dimensions and SHA-256.
- Optional customer-facing semantic label and actor fingerprints for creation/updates.
- Explicit admission/archive timestamps.
- `media_derivatives` table separated from source truth with derivative kind, storage disk/path, MIME, bytes, dimensions, SHA-256 and actor fingerprint.
- Duplicate source hashes, derivative hashes, storage paths and per-asset derivative kinds are database-constrained.
- Typed Eloquent relationships for source -> derivatives and canonical derivative lookup.
- `MediaLibraryService` registers source metadata, attaches derivative metadata, explicitly admits media and archives media.
- Derivative/file metadata presence does not auto-admit an asset.
- Admission requires an explicit canonical derivative plus semantic label.
- Archived media cannot receive new derivatives or silently return to admitted state.
- Absolute local filesystem derivative paths and malformed actor fingerprints fail validation.

## Non-goals preserved

- No upload endpoint or binary processing; CMS-031 owns upload validation.
- No product/variant gallery assignment; CMS-032 owns it.
- No Home/category/editorial assignment; CMS-033 owns it.
- No media binary in `Images/` or `mobile/assets/products/**` is changed.
- Current production-media admission truth and #230 remain untouched.
- Product Master, ASIN, Pantone and Amazon handoff remain unchanged.
