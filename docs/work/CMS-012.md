## Current implementation state

### CMS-012A — public contract foundation

Status: **IMPLEMENTED ON STACKED BRANCH / CI PENDING**

Branch: `agent/cms-012-pdp-layout`
Base: `agent/cms-011-variant-presentation`

Delivered in this slice:

- reserved content identity `pdp.layout` / schema v1;
- compiled allowlist of PDP section IDs: gallery, identity, variants, usage, facts, editorial, specifications and Amazon trust;
- deterministic ordered-section payload requiring every supported section exactly once;
- required-visible protection for gallery, identity, variants, verified facts, specifications and Amazon trust;
- only presentation-safe usage/editorial sections may currently be hidden;
- unknown/duplicate/missing section IDs fail closed;
- non-boolean visibility fails closed;
- unknown private/admin fields are stripped during public normalization;
- additive public endpoint `GET /api/v1/content/pdp-layout`;
- explicit publication requirement, ETag/revision caching and the existing CMS public envelope;
- unit regressions for allowlist/order/visibility/protected-section invariants;
- API regressions for unpublished/typed-versioned/invalid/metadata-stripping behavior.

No Flutter runtime behavior changes are included in CMS-012A. Existing PDP rendering and Amazon handoff remain unchanged until the contract is validated in CI.

### CMS-012B — next stacked slice

After CMS-012A is Green:

- protected typed Admin editor using existing content.view/write/publish/restore capabilities;
- optimistic draft revision and restore UX through the existing CMS revision service;

- full Backend + Flutter + Android release regression gates.

## Guardrails

- stable product/variant identity stays protected;
- Product Master facts, dimensions, care guidance and verified claims stay protected;
- Pantone and ASIN stay protected;
- Amazon destination/purchase architecture stays unchanged;
- no arbitrary remote widget, HTML, URL or executable section type can enter the PDP layout contract;
- CMS-013 related-product authoring remains separate.
